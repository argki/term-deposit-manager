# 定期預金管理アプリ 開発タスクリスト

[要件定義書](./requirements.md) に基づく実装タスク一覧。

## Step 1: 基盤・Docker 環境・データモデル設計
- [x] **プロジェクト初期化・構成整備**
  - `package.json`（TypeScript, React, Vite, Hono, Recharts, Lucide React, Vitest, ESLint, Prettier）作成
  - `tsconfig.json`, `tsconfig.server.json`, `vite.config.ts`, `vitest.config.ts`, `eslint.config.js`, `.prettierrc` 設定
  - `.gitignore`（`node_modules/`, `dist/`, `data/` 実データ等）設定
- [x] **Docker / Docker Compose 環境構築**
  - `Dockerfile`（マルチステージビルド、`node:26-alpine` 等最新 LTS 確認）作成
  - `compose.yaml` 作成（`127.0.0.1:3457:3457` 限定公開、`./data:/app/data` ボリュームマウント）
- [x] **データモデル・型定義設計（`src/shared/types.ts`）**
  - `DepositStatus`（`'active' | 'maturing_soon' | 'matured' | 'rolled_over'`）
  - `DepositRecord`（ID, 銀行名, 預入日, 満期日, 期間年数, 基本金利, キャンペーン上乗せ金利, 合計金利, キャンペーン名/メモ, 金額, 満期利息/受取額, ステータス, `parentDepositId`, `rolledOverToId`, 作成/更新日時）
  - `AppSettings`（まもなく満期判定日数しきい値［デフォルト 90 日］、積替検討しきい値［残存年数・金利基準］）
  - `DepositStore`（`version`, `deposits`, `settings`, `updatedAt`）

## Step 2: ドメインロジック実装・単体テスト（`src/shared/`）
- [x] **ステータス判定・期間・利息計算ロジック**
  - 現在日付と満期日から「あと何日」・残存年数・`maturing_soon` 自動判定を行うロジック
  - 「積替検討候補（残存期間が長く金利が低い）」判定ロジック
  - ポートフォリオ集計ロジック（銀行別小計、全体運用中残高、加重平均金利、まもなく満期件数・金額、満期年別集計）
  - 概算利息計算（税引前・税引後 20.315% 参考値）
  - 上記すべての単体テスト（Vitest）作成
- [x] **Excel 書き出し CSV パーサ実装**
  - A 列銀行名の引き継ぎ、小計行・合計行・空行のスキップ
  - 左ブロック（元預入）と右ブロック（積替先）のパースと親子リンク（`parentDepositId` / `rolledOverToId`）自動生成
  - `"満期終了"` の判定、カンマ・空白・連続ドット等の表記ゆれ正規化
  - サンプル CSV データを用いた単体テスト（銀行別小計・総計の一致検証）作成

## Step 3: ローカル API・永続化層・SSE 同期実装（`src/server/`）
- [x] **JSON 永続化ストア（`src/server/store.ts`）**
  - `/app/data/deposits.json` への安全な読み書き（`.tmp` 経由のアトミック書き込み）
- [x] **Hono API エンドポイント（`src/server/app.ts`）**
  - `GET /api/health`（ヘルスチェック）
  - `GET /api/store`（全データ・設定取得）
  - `POST /api/deposits` / `PATCH /api/deposits/:id` / `DELETE /api/deposits/:id`（預金 CRUD）
  - `POST /api/deposits/:id/rollover`（積替実行：元レコードを `rolled_over` にし、新規レコードを紐づけ作成）
  - `POST /api/deposits/:id/mature`（満期終了実行：`matured` 化と受取利息記録）
  - `PUT /api/settings`（アラート日数・積替検討しきい値更新）
  - `POST /api/import-csv`（Excel 書き出し CSV インポート）
  - `GET /api/export` / `POST /api/import`（JSON バックアップ出力・復元）
  - `GET /api/events`（SSE リアルタイム同期）
- [x] **API 単体テスト（`src/server/app.test.ts`）**

## Step 4: フロントエンド UI 設計・実装（`src/client/`）
- [x] **デザインシステム・テーマ定義**
  - ステータス別の明確なカラーシステム：
    - まもなく満期：青系（スカイブルーティント＋残り日数バッジ）
    - 無効（満期終了 / 積替済）：落ち着いたグレー系（スレートティント＋ミュート文字＋取り消し線/完了バッジ、赤色は使わない）
    - 積替検討候補：アンバー系インジケーター
- [x] **サマリーダッシュボード & グラフ**
  - KPI カード（運用中合計残高、加重平均金利、まもなく満期、積替検討候補）
  - 銀行別残高・平均金利グラフ & 満期年別スケジュールグラフ（Recharts）
- [x] **定期預金一覧テーブル & ビュー切替**
  - 全銀行統合ビュー / 銀行別グループビュー（小計付き）の切り替え
  - ソート（満期近い順、金利低い順、金利高い順、金額順）、銀行フィルタ、ステータスフィルタ（「無効分を表示」トグル、積替検討候補クイックフィルタ）
  - 行ごとのアクション（「編集」「積替」「満期終了」「トレース表示」）
- [x] **預入・積替トレースモーダル / ドロワー**
  - 選択した預金の積替チェーン（親→子→孫）をタイムライン形式で表示し、いつ・どこに・どういう条件で預けていたか一目で追える UI
- [x] **登録・積替・設定・データ移行モーダル**
  - 新規登録・編集フォーム（預入日＋期間からの満期日自動計算、キャンペーン金利合算）
  - 積替（ロールオーバー）専用フォーム（元預金の条件を比較表示しながら新条件を入力）
  - CSV インポート UI（プレビュー確認付き）および JSON バックアップ UI
  - Undo / Redo（`Ctrl+Z` / `Ctrl+Y`）対応と SSE による複数タブ同期
